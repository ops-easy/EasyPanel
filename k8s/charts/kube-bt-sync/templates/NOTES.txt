1. 查看 Service：
   kubectl get svc -n {{ .Release.Namespace }} {{ include "kube-bt-sync.frontendFullname" . }} {{ include "kube-bt-sync.fullname" . }}

{{- $frontend := .Values.frontend | default dict -}}
{{- $frontendService := $frontend.service | default dict -}}
{{- $frontendServiceType := $frontendService.type | default "NodePort" -}}

{{- if .Values.ingress.enabled }}
2. 在 DNS 或 /etc/hosts 中指向 Ingress 入口 IP，访问：
   http{{ if .Values.ingress.tls }}s{{ end }}://{{ (index .Values.ingress.hosts 0).host }}/
{{- else if eq $frontendServiceType "NodePort" }}
2. 使用任意节点 IP + NodePort 访问前端控制台：
   http://<节点IP>:{{ $frontendService.nodePort | default 32080 }}
{{- else }}
2. 端口转发前端 Service（临时）：
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "kube-bt-sync.frontendFullname" . }} 8080:{{ $frontendService.port | default 80 }}
   然后打开 http://127.0.0.1:8080
{{- end }}

3. 首次使用请打开 /setup 完成向导（或预先配置 Secret 中的 BAOTA_* 等环境变量）。

4. 数据目录：PVC {{ include "kube-bt-sync.fullname" . }}-data（若 persistence.enabled=true）。
